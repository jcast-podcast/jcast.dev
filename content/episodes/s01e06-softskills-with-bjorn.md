In deze aflevering starten we vanuit Java als onze vertrouwde basis, maar ontdekken we dat soft skills minstens zo bepalend zijn voor succes.  
We hebben het over de eerste keer dat Java je écht pakt, de sprong van solo-code naar teamwork, en de momenten waarop communicatie belangrijker wordt dan techniek.

Te gast: **Björn De Craemer**, Java-fanaat en iemand die als geen ander weet dat software niet alleen over code gaat, maar ook over mensen.

Met onder andere:
- Hoe Java ons allemaal het vak in trok en hoe die rol evolueerde
- De overgang van code kloppen naar samenwerken in teams
- Soft skills die je sneller vooruit helpen dan technische kennis
- Het belang van feedback, eigenaarschap en communicatie
- Herkenbare verhalen over toxische samenwerking én hoe je dat doorbreekt
- Advies voor je jongere zelf: welke soft skill je écht meteen had moeten leren

En natuurlijk: een pittige **Quick Fire ronde** met dilemma’s van *1-op-1 met je manager: chill of spannend*, tot *hard feedback overbrengen of diplomatiek verpakken*. 

Of je nu zelf Java schrijft, of gewoon benieuwd bent hoe mensenwerk en techniek in balans komen: deze aflevering zit vol herkenbare verhalen, inzichten én een paar wijze lessen van Björn.
