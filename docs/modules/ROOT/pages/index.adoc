= jcast.dev
:description: Documentatie van de website van JCast.

De website van JCast: een statische Hugo-site met afleveringen, blog en crew-info, gehost op AWS (S3 + CloudFront).

Deze documentatie leeft naast de code, in `docs/`, en wordt mee gereviewd in elke pull request.
Pas je iets aan aan de site? Dan pas je de pagina hier mee aan.

== Voor wie is wat?

Niet iedereen heeft hetzelfde detailniveau nodig.
