= Lokaal draaien

== Eenmalig installeren

[source,bash]
----
brew install hugo asciidoctor
gem install rouge          # syntax highlighting in codeblokken
hugo version               # moet 'extended' bevatten
----

Asciidoctor is een Ruby-tool die Hugo als externe binary aanroept.
Zonder Asciidoctor bouwt de site niet meer.

== Site starten

[source,bash]
----
hugo server -D
----

Open http://localhost:1313.
`-D` toont ook drafts.

== Productiebuild testen

[source,bash]
----
hugo --minify
sh scripts/verify-image-output.sh
----
