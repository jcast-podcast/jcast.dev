= JCast – De Podcast over IT, Dev Life & Gezonde Meningsverschillen

De codebase van https://jcast.dev[jcast.dev]: een statische https://gohugo.io/[Hugo]-site, gehost op AWS en onderhouden door de JCast crew: Oumaima, Viktor en Maarten.

== Snel starten

[source,bash]
----
brew install hugo asciidoctor
gem install rouge
hugo server -D
----

Open http://localhost:1313.
